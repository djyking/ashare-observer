# A 股观察台

一个本地运行的 A 股日线研究与模拟持仓看板。Python 标准库后端、原生 JavaScript 前端；无第三方依赖，无证券账户凭据，不提交真实订单。

## 启动

需要 Python 3.12 或更新版本。在本目录运行：

```text
python -m ashare_monitor
```

打开 http://127.0.0.1:18766 。Windows 用户也可以双击本目录的“打开A股观察台.cmd”。服务只监听本机地址。

从 GitHub 获取后运行：

```text
git clone https://github.com/djyking/ashare-observer.git
cd ashare-observer
python -m ashare_monitor
```

首次启动默认使用可离线运行的合成行情，不需要账户或密钥。要查看真实日线，请在“数据与设置”中选择公开行情。

```text
python -m unittest discover -s tests -v
```

## 可以做什么

- 查看股票观察列表、日线图、EMA、MACD、RSI、ATR 和成交量变化。
- 使用公开教学规则生成可解释的观察评分和研究情景；允许没有观察信号。评分不是盈利概率，情景价不是预测必达价。
- 区分演示数据、公开日线行情与本地 CSV 数据，显示数据日期和获取错误。
- 使用独立模拟账户登记下一交易日委托，检查 T+1 可卖数量、数量单位、费用、停牌和涨跌停。
- 分页查看扫描历史、模拟委托、成交及盈亏。刷新行情不清空账本，重启后恢复记录。
- 修改观察代码、数据模式和后台扫描间隔。日线行情在下一次收盘后刷新，避免盘中反复分析未收盘 K 线。

## 三种数据模式

| 模式 | 数据用途 | 模拟下单 |
|---|---|---|
| 离线演示 | 固定种子的合成日线，初始演示日期 2026-10-12 | 可用；手动推进演示交易日后撮合 |
| 公开日线 | 网络获取的已收盘历史行情；来源和复权口径明确标注 | 关闭，仅研究 |
| 本地 CSV | 自行准备且有权使用的日线资料 | 关闭，仅研究 |

演示采用真实股票代码便于理解，但**演示股价、成交量、评分和收益全部是合成的，不代表真实市场表现**。演示时钟与电脑时间分开显示。推进交易日是情景演练，不是对未来行情的预测。

公开接口可能限流、延迟、变更或不可用。系统不把抓取时间冒充市场成交时间，也不使用演示价格填补真实数据的空缺。本项目不提供交易所授权实时行情服务；具体使用与再分发须遵守数据提供方条款。

## 研究与模拟的边界

技术指标只使用所选截止日期之前的已收盘日线。真实行情分析使用注明口径的历史序列；复权价格不能直接当作实盘委托价格。模拟成交仅使用演示原价序列，信号观察后提交的委托最早在后续交易日开盘处理，避免用同一根收盘信号假设自己已经在该收盘价成交。

模拟交易包括日线级近似、费用假设和滑点；不复现逐笔撮合、排队、盘口容量及全部公司行动，不宣称等价于券商成交或策略已经具有盈利优势。真实行情和 CSV 模式下展示的模拟账本仍使用独立演示行情计价，不混用资金或价格。

初始模拟资金 100,000 元；不提供杠杆、融资、做空或自动实盘接口。持仓资金和成交记录独立于研究评分，不会因为切换数据源而重置。

交易日历覆盖 2025—2026 年。年份超出覆盖范围时明确拒绝模拟推进，需要先更新官方日历。T+1、涨跌停、数量与费用约束见规则模块；风险警示、新股或元数据不足等特殊股票只观察，不假设普通股票规则适用。

## 目录

```text
ashare_monitor/
  data.py          日线来源与校验
  analysis.py      教学指标与观察规则
  rules.py         A 股日历和市场规则
  portfolio.py     模拟委托、成交与账本
  storage.py       SQLite 原子持久化、扫描历史分页
  runtime.py       后台采集、发布与调度
  server.py        本机 HTTP 接口
  web/             可视化看板
tests/              单元和接口测试
docs/               数据、规则和接口说明
var/                本机数据库与导入目录，不应发布
```

原始股票历史与模拟成交是两个不同用途的数据集。扫描历史保留最近 2,000 次；模拟账本不随扫描历史清理。数据库默认位于 `var/research.sqlite3`，CSV 默认位于 `var/imports`。

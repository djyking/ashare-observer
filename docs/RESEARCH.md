# 历史策略研究与结果比较

历史研究把“数据 → 日线信号 → 次日开盘模拟成交 → 费用后净值 → 回撤与逐笔复盘”连接起来。它是独立的研究实验，不连接券商，也不会修改演示账户的现金、持仓或委托。

## 使用步骤

1. 打开“历史研究”页，选择公开真实日线、本地 CSV 或合成演示数据。
2. 输入研究股票池及开始、结束日期。结束日期不能晚于最近已收盘交易日。建议先用较少股票验证数据质量，再扩大到最多 50 只。
3. 选择一条策略，设定初始资金、最多持仓数、每仓资金比例、佣金、印花税、滑点、止损、目标和最长持仓交易日数。
4. 提交后后台运行。查看报告的“警示/假设”和被排除股票，再看收益、回撤与逐笔成交；不要先按收益挑结果。
5. 复制同一股票池、区间、资金与费用配置，分别运行三条策略，比较报告。数据指纹不同代表使用的数据不同，不能当成只有策略参数发生了变化。
6. 不再查看的实验可以归档。实验结果、参数、数据指纹和采集快照保存在本地数据库，重启后仍可读取，不随刷新变化。

真实行情模式可以研究真实历史价格，但不会启用任何账户下单。CSV 要声明价格复权方式：只有已明确声明不复权，或同时提供对应原价列，才可用于成交回放；只有复权价格的 CSV 仍可分析指标，但不能冒充历史成交价。

## 三条公开示例策略

评分只描述条件，不是胜率。没有哪一条被预设为更赚钱；回放可能没有成交，也可能持续亏损。

| 策略 | 默认条件 | 用途与局限 |
| --- | --- | --- |
| 教学综合评分 | 总分至少 70；RSI ≤ 75；收盘价高于 EMA20 的幅度不超过 8%；有成交量 | 用均线、动量、RSI 和量比解释状态，不会因为评分高就连到真实账户下单 |
| 上升趋势回调 | 总分至少 60；EMA20 ≥ EMA60；收盘价在 EMA20 上方且距其不超过 3%；RSI 40～65 | 观察趋势中靠近均线的价格，仍可能是趋势结束前的反弹 |
| 放量突破 | 总分至少 60；EMA20 ≥ EMA60；收盘价突破**之前**20 日最高价；量比 ≥ 1.5；距 EMA20 不超过 8% | 突破窗口不包含信号当日；可能遇到假突破或次日跳空 |

每条策略都有启用开关及可配置参数，策略版本为 `public-v2`。当前五项评分各最多 20 分：

| 项目 | 规则 |
| --- | --- |
| 价格趋势 | 收盘价 ≥ EMA20：20 分，否则 0 分 |
| 中期趋势 | EMA20 ≥ EMA60：20 分，否则 0 分 |
| MACD 动量 | DIF − DEA ≥ 0：20 分，否则 0 分 |
| RSI 均衡 | RSI14 在 45～65：20 分；在 35～75：10 分；否则 0 分 |
| 成交量 | 当日成交量/前 20 日均量在 0.8～2：20 分；其他正值：5 分；无量：0 分 |

图表直接使用后端同一套 EMA、MACD、RSI、ATR 序列。EMA 以前 N 根的简单均值初始化，再递推；初期不足的数据返回空值，不用零值伪造均线。历史触发点记录条件从不满足到满足的日期，实际回放每天重新检查条件，空仓且条件持续满足时可以再次生成新指令。

## 成交时序与资金

例如：周一收盘形成信号，周二开盘尝试买入。周二收盘已达到退出条件，最早周三开盘尝试卖出，满足 T+1。信号当日收盘不成交；不会假设当天最高价或最低价就是实际可以买卖的价位。

- 退出条件是收盘达到止损、目标或最长持仓日数。目标/止损并不保证下一开盘仍能按此价格成交。
- 最长持仓按交易日计算，买入当天计为第 1 天；设为 1 时，买入当天收盘形成时间退出信号，下一交易日开盘卖出。
- 每个开盘先尝试卖出，再按上一日信号评分降序、股票代码升序尝试买入。
- 不重复加仓同一股票，持仓数量受上限约束。单仓预算是“上一时点可知的总权益 × 单仓比例”，且不超过现金；需预留买入费用。
- 主板/创业板买入必须 100 股整数倍，科创板至少 200 股，北交所至少 100 股；因此低本金可能根本买不进某些股票。
- 未成交指令当日失效，不跨过停牌或缺失数据自动挪到未来某天。之后的新收盘信号可以再次尝试。
- 区间末尾不强制卖出。最终净值包括未实现盈亏；胜率只统计已经卖出的完整仓位，没有平仓时显示“无样本”。

## 费用、滑点与流动性

默认双边佣金 `0.0003`（万三），每笔最低 5 元；卖出印花税 `0.0005`（万五）；滑点 5 bps（0.05%）。这些都是研究参数，**不是确认过的个人券商费率**，没有单独模拟过户费。成交价格按人民币分舍入。

买入价 = 次日开盘原价 × (1 + 滑点)；卖出价 = 开盘原价 × (1 − 滑点)。如果含滑点价格越过当日 OHLC 或板块涨跌幅范围，则不编造成交。买入开盘涨停、卖出开盘跌停、零成交量、前收原价缺失时也拒单。

数量先以**前一交易日**成交量的 1% 作上限，再用实际成交日的总量作保守校验；超过实际日量 1% 的整笔指令被拒绝，不用未来成交量改变委托数量。日线没有盘口、分时成交和排队信息，这只是保守的研究成交模型，不能等同真实开盘订单模拟。

## 怎样读报告

- **总收益**：最终净值/初始现金 − 1，包含未平仓估值。
- **最大回撤**：每日收盘净值相对之前最高净值的最大下降幅度；不能看到盘中更深的回撤。
- **成交数**：买卖两侧分别计数。平仓数是已经完整退出的仓位数。
- **已平仓胜率**：扣除该笔买卖费用后的盈利平仓数/全部平仓数；不包含浮盈持仓，不能从少量样本推断未来概率。
- **费用**：实际模拟成交的佣金和印花税合计。滑点已体现在成交价中，不重复计费。
- **基准**：区间开始时把本金等分到被纳入的股票，以相同整手、佣金、滑点、流动性和涨跌幅约束买入后持有；买不到的份额保持现金，不再平衡。不是指数收益。
- **拒单**：看清是最低股数、现金、仓位上限、涨跌停、无量、数据缺失还是区间结束。没有成交可能是合理结果。
- **数据指纹**：原价、指标数据、股票代码、板块、来源及复权方式的 SHA-256。保持相同指纹有助比较，但无法消除数据源本身的偏差。

## 必须保留的研究边界

1. 当前实现只使用已核实的 2025、2026 年交易日历。未知年份不猜测成交日。
2. 至少需要 60 根日线预热。请求区间早于预热完成日，会显示覆盖警示并持有现金；请求区间晚于已采集数据，也会明确提示，不能声称完整覆盖。
3. 真实数据的上市日期及历史风险标记没有全部独立核验。可以基于“成熟普通股”的明确假设做研究，但排除已知 ST、退市风险、未知板块和已知待处理公司行动；这不构成实盘规则授权。
4. 指标前复权价格可能事后重算，不是 point-in-time 数据；当前观察股票池存在幸存者偏差与选择偏差。该研究不能证明策略有可交易优势。
5. 未实现完整现金分红、送配股等公司行动账务。检测到复权/原价比例发生明显变化时，报告标记 `invalid_corporate_actions`，停止该股票的后续模拟成交；报告权益可能失真，**不可把收益指标作为有效绩效**。应使用不跨公司行动的区间，或在后续版本加入经过验证的公司行动数据。
6. 缺失日线不会填造行情。持仓缺价使用最后可用原价估值，并显示缺价数量；这可能掩盖真实回撤。策略不能据陈旧价格新增买入。
7. 收益高不代表稳健。比较相同区间之外，还需要独立的后续区间验证、不同市场环境、参数敏感性及足够成交样本；本版没有宣称实现自动参数寻优或统计显著性检验。

## 程序接口

- `GET /api/strategies`：策略目录、默认参数及说明。
- `POST /api/research`：后台创建研究实验。需要同源校验和 `X-CSRF-Token`，返回实验 ID。
- `GET /api/research`：研究实验列表。
- `GET /api/research/{id}`：配置、状态、结果、错误信息；行情数据快照保存在服务端，不把大数据随列表返回。
- `POST /api/research/{id}/archive`：归档实验。

核心可独立调用，无网络与账本副作用：

```python
from ashare_monitor.data import load_market
from ashare_monitor.research import run_research

# 先在可信来源采集；源失败不会替换成随机合成价格。
market = load_market("eastmoney", ["600036", "000333"], "2026-10-12")
report = run_research(market["stocks"], {
    "start_date": "2026-01-05",
    "end_date": "2026-10-12",
    "strategy_id": "pullback",
    "initial_cash": 100000,
    "max_positions": 2,
    "position_pct": 40,
    "commission_rate": 0.0003,
    "minimum_commission": 5,
    "stamp_tax_rate": 0.0005,
    "slippage_bps": 5,
    "stop_loss_pct": 5,
    "take_profit_pct": 10,
    "max_holding_days": 20,
})
print(report["warnings"])
print(report["metrics"])
```

固定公开示例参数和算法是可审查的教学基线，不声称复制任何私有交易策略。

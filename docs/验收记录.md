# A 股量化交易研究平台验收记录

验收日期：2026-10-13，版本 1.2.0。

## 本轮完成

- 公开教学趋势、上升回调、放量突破三种可配置策略；开关、阈值、逐项条件和评分拆解。
- 图表与后端共用 EMA20/60、MACD、RSI、ATR、量比序列；筛选和详情联动，历史信号每页 10 条。
- 股票名称/代码搜索、模板、自定义分组，观察列表和研究池上限 50 只。
- CSV 下载模板、UTF-8 文件/文本导入、逐行校验、1 MB 限制与明确覆盖。
- 独立历史回放：已收盘信号、次日开盘成交、T+1、板块股数、涨跌停、停牌、费用、滑点、持仓与退出参数。
- 报告含权益、回撤、基准、胜率、费用、逐笔成交、拒单、历史信号、参数、版本和数据指纹；实验对比、参数复用及归档。
- 模拟订单预检查；修复次日卖出被额外延后一天、资金/股数错误信息被遮蔽的问题。
- 新建演示实验先原子归档旧账本，历史研究独立运行，不改动演示资金和仓位。
- 扫描明细按原始结果保留；交易记录服务端分页，摘要不重复传输完整账本；实验列表与启动恢复避免加载全部输入数据。
- 修复历史回放的上市前虚假成交、最低佣金重复预扣边界。公司行动无法准确还原时，列表明确显示结果失真而非有效业绩。

| 真实公开日线 | 浏览器完成两次 600036、000333 历史实验，来源为东方财富公开日线；非合成数据替代 |

| 浏览器操作 | 研究提交、轮询完成、参数复用、报告、比较、归档、策略设置保存、模拟预览/提交/撤销均验证 |

| 持久化与异常 | 原子归档失败不改旧账本，研究失败可查看原因，中断任务不会永久 running，旧历史无明细时明确提示 |

自动测试的人工构造行情只验证程序行为，不用于证明真实策略收益。真实公开数据的成功读取不保证未来接口一直可用。GitHub Actions 对本次提交另行运行 Windows 和 Ubuntu 检查，以对应提交的 CI 结果为准。

# A 股量化交易研究平台验收记录

验收日期：2026-10-13，版本 1.1.0。

## 已实现

- 本地 Python 后端、Vue 3 + TypeScript + Vite 可视化页面、SQLite 持久化和后台日线扫描。
- 离线合成行情、公开已收盘日线、本地 CSV 三种独立数据模式。
- EMA、MACD、RSI、ATR、成交量比较，以及公开教学规则的研究评分与价格情景。
- A 股交易日历、T+1、板块申报数量规则、涨跌停、费用和下一交易日开盘模拟撮合。
- 研究历史每页 30 条；委托、成交、资金和持仓独立记录。
- 券商账户适配接口、可用的模拟实现、明确未连接的实盘占位和离线扩展示例。

## 适用边界

当前交付是日线研究与模拟软件，已提供券商适配扩展点，尚未接入具体券商，也没有启用实盘自动下单。教学评分没有经过收益有效性验证，不表示盈利概率。日线模拟不复现逐笔撮合、排队、完整公司行动或真实券商成交。

公开来源可能延迟、限流或变更；本次成功不保证持续可用。交易日历覆盖 2025—2026 年，超出范围会拒绝推算模拟交易日，需先更新官方日历。

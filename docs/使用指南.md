# A 股量化交易研究平台：使用指南

1. 双击项目根目录的“打开A股观察台.cmd”，或运行 README 中的 Python 启动命令。
2. 先查看顶部数据模式和日期。“离线演示”中的数字均为合成场景，不是证券实时价格。
3. 在观察列表选择股票，查看日线、指标、观察理由和研究情景。
4. 若要试验账本，在演示模式提交买入股数。委托进入等待状态，不会立即按当前收盘成交。
5. 点击推进演示交易日。符合资金、数量和价格约束的委托在该日开盘模拟成交；未成交委托当日失效并释放冻结资金，不跨日自动续单。同一天买入的数量不可立即卖出。
6. 买入当日的“当前可卖”为 0，但收盘后可以预约下一交易日开盘卖出。先看订单预览里的“执行日可卖”，提交卖单后再推进一天即按 T+1 检查撮合，不必多等一天。无成交可能来自停牌、涨跌停、规则不符或资金不足，原因保留在委托中。
7. 切换公开行情后，观察真实日线资料与来源日期。此模式不开放模拟下单，演示账户仍独立保存。
8. 来源出现错误时先查看错误说明。可以返回离线演示，或导入有权使用的 CSV；系统不会悄悄替换成合成行情。

## 券商接口状态

打开“券商接入”页面，可以填写所选适配器的账号、密码及连接参数。先用离线示例熟悉操作：

1. 选择“离线券商示例”，输入演示账号 `demo`、演示密码 `demo123`。
2. 保存配置。此时尚未连接；账号密码只保留在当前服务的内存中，表单密码会清空。
3. 验证连接。成功后查询资金、持仓、委托、成交；这些是独立的虚构固定数据，不是你的账户，也不是手动模拟账本。
4. 断开连接会清除会话凭据。服务重启后也需要重新填写，不会自动恢复登录。

“真实券商（接入预留）”只保存接入资料，未安装具体驱动时无法连接。不同券商可能使用资金账号与密码，也可能要求本地交易客户端、令牌或其他认证；实际字段由官方适配器定义。不要在预留项里输入真实密码来尝试解除未接入状态。

现有模拟适配器仍使用独立演示账本，遵循 T+1、数量和资金约束。网页券商连接只提供读取；本版本不能提交或撤销证券账户的真实订单。

准备具体接入时，先向所选券商确认接口权限、费用、支持的软件环境和测试方式，再按 [券商适配指南](BROKER_ADAPTER.md) 开发与验证。不要把账号、密码、密钥或身份资料提交到 GitHub。

## 更新页面

正常使用只需 Python，Vue 前端已构建在仓库内。修改前端源码后需要按 README 运行前端测试和生产构建，再刷新看板；仅修改 `frontend/src/` 不会自动改变 Python 提供的页面。开发时可以使用 Vite 开发服务器查看即时变化。

关闭浏览器不会停止本机后台进程；本工具没有开机自启配置。重新双击入口会复用已运行服务。终端前台运行时可用 Ctrl+C 停止。

历史评分是教学观察分，不是胜率。目标价和止损价仅用于说明波动场景，不保证达到或按该价成交。

## 完成一次策略研究

1. 在“数据与设置”选择股票池。可以按代码或名称搜索、应用示例模板或保存自定义分组；最多 50 只，不代表扫描整个市场。
2. 查看并配置三类策略：教学趋势、上升回调、放量突破。设置页保存会重新计算当前观察结果，既有历史报告不会被改写。
3. 打开“历史回放”，选择来源、股票池、日期、策略、初始资金、每仓比例、持仓数、费用与退出参数，提交后台运行。建议先用短区间和少量股票核对数据。
4. 读取权益曲线、净收益、回撤、基准、成交和拒单。无成交时先看历史信号和拒单原因；公司行动导致估值失真时，不以报告数字证明策略收益。
5. 改变一个参数后新建另一实验，并勾选报告做对照。对比时保持数据标识、日期与成本参数一致；不同股票池或时间区间不能简单按收益排名判断优劣。需要检验泛化时，应另选未用来调参的时间段。
6. 完成后可以归档实验。报告、参数、数据标识和研究输入保存在本机数据库；不会把研究结果写入手动演示账户，也不会连接券商真实交易。

## 导入自己的日线

在股票池管理中下载 CSV 模板。模板的两行价格仅用于说明格式，不能直接当作真实数据。选择一个股票代码和 UTF-8 CSV 文件（不超过 1 MB），先校验，按返回的行号和字段修正问题，再导入。已有不同内容时需要勾选覆盖。

文件保存在 `var/imports/<六位代码>.csv`。导入后可在观察设置或历史回放中选择 CSV 来源。若需要模拟历史成交，`adjustment=none` 表示原价；`qfq` 则应另提供 `raw_open/raw_high/raw_low/raw_close`。未声明可靠原价时可看指标，但不能编造成交价格。

## 保留多个演示实验

模拟账户里可以填写名称、初始资金和已核实的交易日起点，新建独立演示实验。旧持仓、委托、成交和统计会先完整归档；旧委托停留在归档中，不继续执行。当前账本从新资金开始，不拼接旧实验的收益。归档列表可按需展开查看；日常轮询和交易列表均不再整本传输。

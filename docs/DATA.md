# 日线数据与教学指标

## 三种独立模式

- **离线演示**：固定随机种子从 2025-01-02 生成。新增交易日不改变此前行情，交易日使用内置已知日历。股票名称用于演示界面，合成价格与同名公司的真实走势没有对应关系。演示不访问网络；模拟收益不能作为策略有效性的证明。
- **在线日线**：东方财富公开只读接口，分别请求前复权和不复权序列。每条序列只请求一次，网络超时为 6 秒，最多并行 4 只股票；本次失败显示不可用，下次手动或定时刷新再请求，不替换为演示数据。行情可能延迟，接口可用性与使用许可需自行核实。
- **CSV**：读取应用数据根目录下固定 `imports` 目录中的六位代码文件，例如默认 `var/imports/600519.csv`。设置页面提供模板下载、文本/文件预校验和导入；不接受网页传入的任意系统路径。用于独立研究与历史回放，不能驱动手动演示账本或券商账户。

真实模式只读取当前已收盘交易日及之前的数据。原价缺失不会阻止复权指标展示，但不生成原价情景。在线接口没有提供独立核实的上市日期和完整风险名单，`metadata_verified=false`；不能据此声称股票不是新股或没有风险标记。

如果最后一根日线早于观察日，标记为 `stale=true`，同时保留实际 `data_date` 和请求的 `as_of`。这种情况可能来自停牌或源延迟，不能仅凭缺少一根日线判断具体原因。历史指标仍可查看，但不列为当前“观察”机会，也不生成当前价位情景；错误摘要促使后续定时扫描重试。

前复权会随分红、拆股等事件重算。下载到的历史前复权序列不是历史当天可获知数据版本，不应直接用于声称“无未来数据”的真实历史收益回测。本项目的独立历史回放限制信号只看当日收盘及以前的数据、次日开盘执行，并使用原价成交，但不能消除复权重算、股票池选择和缺少历年风险名单等资料偏差。

## 股票池与搜索

设置页面支持 1～50 只观察股、最多 20 个分组，以及预置演示、银行研究、科技制造研究模板。分组是方便切换的研究目录，不是自动交易配置。仍有演示持仓或待成交委托的股票不能从当前观察列表移除。

搜索支持六位代码和中文名称。常见本地目录匹配直接返回；未匹配时尝试东方财富公开证券搜索，单次超时 2 秒，失败保留本地结果。代码前缀能识别板块，但不能证明证券存在或仍在上市。搜索返回来源、研究用途和 `demo_tradable`；上市日期、风险状态统一标记未独立核实，不捏造上市资料。只有八只预置合成样本具备手动演示交易元数据，新增代码可研究，不自动取得演示买卖资格。

## CSV 列

UTF-8 或 UTF-8 BOM 编码，逗号分隔，日期必须升序且不重复：

```csv
date,open,high,low,close,volume,amount,adjustment
2026-10-09,10.00,10.50,9.90,10.30,2000000,20400000,none
2026-10-12,10.35,10.60,10.20,10.40,1800000,18700000,none
```

`date/open/high/low/close/volume` 为必需列。价格为人民币元；`volume` 必须是**股**，不是手。`amount` 为人民币元，可省略（记为未知金额 0，不用于评分）。`adjustment` 只能统一为 `none`（明确未复权）或 `qfq`（前复权）。未填写时字段值标记 `none`，另以 `adjustment_verified=false` 表示口径未知，不把该序列视为可靠原价。

提供 `qfq` 时，可追加 `raw_open/raw_high/raw_low/raw_close` 四列原价。所有记录必须有这四列才作为有效原价序列。原价不会用复权价冒充。非有限数、负成交量、不合法 OHLC、乱序、重复日期、周末，以及 2025～2026 年内已核实的节假日均拒绝读取；不会排序或修补来掩盖错误。其他年份的历史资料仍可读取，但明确返回 `calendar_verified=false` 和 `calendar_unverified_years`，只检查格式与周末；不能把未覆盖年份当成已核实的模拟交易日。

网页导入原始 UTF-8 文本上限 1 MB、最多 15,000 行。先预校验，页面返回字段、物理行号、起止日期、条数和错误/警告列表；校验不会写文件。提交时再次校验，通过后原子保存到固定目录。已有不同内容必须显式确认覆盖，相同文本重复导入幂等；拒绝任意路径、符号链接、目录联接。模板中的两行价格是格式示例，需要替换为自己的已核实资料，不是历史样本或绩效依据。少于 120 根日线会提示预热/验证样本不足。

## 公开教学指标与观察分

仅使用已收盘日线：EMA20/60、MACD12/26/9、Wilder RSI14、Wilder ATR14。MACD 柱为 DIF-DEA，不额外乘 2。成交量相对值为当日成交量除以前 20 根日线的平均成交量（不含当日）。至少 60 根日线才有完整观察分。

| 项目 | 规则 | 分值 |
|---|---|---|
| 价格趋势 | 收盘价不低于 EMA20 | 20，否则 0 |
| 中期趋势 | EMA20 不低于 EMA60 | 20，否则 0 |
| 动量 | MACD 柱非负 | 20，否则 0 |
| RSI 区间 | 45 至 65；否则 35 至 75；其他 | 20 / 10 / 0 |
| 成交量 | 相对量 0.8 至 2；其他正值；无成交 | 20 / 5 / 0 |

满分 100，仅表达这些教学条件的符合程度，**不是盈利概率或买入权限**。页面展示各项得分、规则、EMA20/60、ATR、RSI、MACD 和量比。图表直接使用后端同一套 EMA 序列，起始周期采用简单均值预热，不再独立使用另一种前端初始化公式。

教学综合、上升趋势回调、放量突破三条公开研究规则可分别启停和配置；默认教学综合门槛仍为 70 分、RSI 不超过 75、距 EMA20 涨幅不超过 8%。回调要求均线趋势向上且靠近 EMA20，突破要求收盘超过此前 N 日最高价并放量；突破区间不包含当天。观察卡片标明实际符合哪条已启用规则，任何规则符合都仅产生研究机会，不自动生成账户委托。参数保存在扫描快照和研究实验中，便于回看当时判断依据。

如有同日可靠原价，情景参考价为该原价收盘；下界为参考价减 1.5 ATR，上界为参考价加 2 ATR。复权 ATR 按同日价格比例换算至原价尺度。这仅是波动幅度情景，百分比字段不表示预期收益概率，也未计手续费、跳空与无法成交风险。

图内信号历史记录条件从不满足转为满足的日期，并使用该日期及之前的指标。扫描历史每页 30 条，展开时读取当次完整股票分析、指标、原价情景、理由、数据来源和策略版本；旧版本只保存摘要的记录会说明没有可补造的历史详情。最近 2,000 次扫描保留，独立实验与账本不按这一规则裁剪。观察信号不等于成交，不能在看到收盘信号后假定自己成交于同一根日线的收盘价。
